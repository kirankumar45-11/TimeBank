# ⏳ TimeBank – Skill Exchange Platform

TimeBank is a community-driven skill exchange platform built using Django. The platform allows users to teach skills, learn from others, and exchange knowledge using a virtual currency called **Time Coins**.

Instead of paying money, users earn and spend coins by sharing their expertise with the community.

---

# 🚀 Features

## 👤 User Authentication

* User Registration & Login
* Secure Authentication System
* Profile Management

## 🎓 Learning & Teaching

* Create and Manage Courses
* Browse Available Courses
* Enroll in Courses
* Dual Role Support (Instructor & Learner)

## 💰 Time Coin Wallet

* Every new user receives **50 Time Coins**
* Earn Coins by Teaching
* Spend Coins to Learn
* Transaction Tracking System

## 📺 Interactive Course Content

* YouTube Video Integration
* Notes & Learning Resources
* Category-Based Course Listing

## 📱 Responsive UI

* Modern and Clean Interface
* Mobile Friendly Design
* Smooth User Experience

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/TimeBank.git
cd TimeBank
```

## 2️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 3️⃣ Install Dependencies

```bash
pip install django pillow
```

---

## 4️⃣ Apply Migrations

```bash
python manage.py migrate
```

---

## 5️⃣ Create Superuser (Optional)

```bash
python manage.py createsuperuser
```

---

## 6️⃣ Run the Development Server

```bash
python manage.py runserver
```

Open your browser and visit:

```bash
http://127.0.0.1:8000/
```
